Used when “Only sites in the allow-list” is selected.
Pages on these hosts are never scanned.
Scripts served from these hosts are skipped (analytics, ads, consent banners …).

Detection rules

Built-in rules. The DOM-sink rules are off by default because they are noisy; turn them on to hunt for DOM XSS.

Custom rules

One rule per line: Name | severity | regex. Severity is critical, high, medium, low or info (info rules go to Intel). Write the regex as /pattern/flags or plain. If it has a capture group, group 1 is reported. Lines starting with # are ignored.
